# Alaska is a text formatter for web prose

It applies proper quotes, no-break spaces, dashes, arrows, symbols, and more; tries to leave ambiguous text as written and keep formatting idempotent.

Examples write a non-ASCII character as `{U+XXXX}`, meaning one character with that codepoint (`{U+00A0}` is a no-break space, `{U+202F}` a narrow one, `{U+2060}` a word joiner, `{U+FE0E}` forces text presentation). It is documentation notation, not input syntax.

## Setup

One engine, `src/core.js`, three ways to run it.

### Browser

Link `browser/alaska.js` (generated by `deno task build`) in the head of a page. It exposes no global and no JS API; configuration is classes, `lang` and `data-*` attributes.

```html
<html lang="en">
  <head>
    <script src="browser/alaska.js"></script>
  </head>
  <body class="alaska">
    <p lang="ru">Alaska applies Russian conventions to this element.</p>
    <p class="alaska-skip">Alaska does not format this element.</p>
    <div class="alaska-observe">Alaska formats nodes added to this element later.</div>
  </body>
</html>
```

| Class            | Effect                                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| `alaska`         | Text inside the element is formatted. Only the outermost `.alaska` is a root; nested ones are traversed normally. |
| `alaska-skip`    | The element and its subtree are not formatted.                                                                    |
| `alaska-observe` | Nodes added inside this element after load are formatted. Must be on or inside an `.alaska` element.              |

`code`, `pre`, `samp`, `kbd`, `script` and `style` are always skipped. Observer limits: added or replaced nodes are formatted (`innerHTML`, `textContent = "..."`), in-place edits of an existing text node (`textNode.data`) are not; quotes pair only in nodes added at a block start or in added blocks, and a minus or line-start dash at the start of other added nodes is skipped.

### CLI

Rewrites HTML files in place, at build time. Only text inside `.alaska` elements changes.

```sh
deno run -R -W cli/cli.js page.html docs/*.html --exclude 'docs/drafts/*'
```

`--exclude <pattern>` is repeatable and matched against each path exactly as given (`*` matches anything including `/`, `?` one character, `[abc]` a class). Exit code is 1 if no files are given or any file fails. `lang`, `data-*`, `alaska-skip` and the skip elements work as in the browser; `alaska-observe` has no effect. The parser is a streaming rewriter, not a full HTML parser.

### Vendored core

```js
import { commonRules, formatString, mathRules, resetCarry } from "./vendor/alaska/core.js";

formatString("5 meters", commonRules, "en"); // 5{U+00A0}meters
formatString("5 meters 50 %", { placeNumberNbspWord: true }, "en"); // only the listed rules are on
```

`formatString(text, rules, lang, carry)`: `rules` is required, and a missing key counts as off. `commonRules` holds the prose defaults, `mathRules` is the [math zone](#math-zones) overlay. `lang` may be `undefined`. Input over 2,000,000 characters is returned unchanged. Call it on whole text blocks (paragraph, heading, cell), not fragments.

Text split by inline elements (`Hello <b>x</b>`) reaches `formatString` in pieces. Pass the same `{}` as `carry` to every piece of one block, in document order, so quote pairing, the minus sign and the line-start dash read across the boundary, call `resetCarry(carry)` at every block boundary (`blockTags` lists them), and feed `"\n"` for `<br>` and `"x"` for inline `<code>`, discarding the output.

## Language

`lang` comes from the nearest element's `lang` attribute (browser, CLI) or the `lang` argument (core); `lang=""` inherits in the browser but resets in the CLI. Only the primary subtag counts (`en`, `EN` and `en-US` are all `en`); `en_US` and `english` are not recognized.

`en` and `ru` are supported. Four rules are language-dependent and are on for `en` and `ru` only: quotes and apostrophes, the short-word no-break space, the numeric range, the em dash. Every other rule is language-independent. Other languages are not supported yet, and what the language-dependent rules do for them is not specified.

| Language         | Quotes                                                   |
| ---------------- | -------------------------------------------------------- |
| `en`             | outer `{U+2018}...{U+2019}`, inner `{U+201C}...{U+201D}` |
| `en-US`, `en-CA` | outer `{U+201C}...{U+201D}`, inner `{U+2018}...{U+2019}` |
| `ru`             | outer `{U+00AB}...{U+00BB}`, inner `{U+201E}...{U+201C}` |

## Rules

18 rules, all on by default except `placeArithmeticalSymbols`.

| Rule                           | Raw            | Formatted                                                                                                                                                                                                         |
| ------------------------------ | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `placeNumberNbspWord`          | `5 meters`     | `5{U+00A0}meters`. Also `50 %` and `100 {U+20AC}` give `{U+202F}` before the sign. Never inserts a space or moves a sign.                                                                                         |
| `placeArithmeticalSymbols`     | `x - 5`        | `x {U+2212} 5`. Math zones only. Spaced `-`, `*`, `/` become U+2212, U+22C5, U+2215.                                                                                                                              |
| `placeMinusSign`               | `-5`           | `{U+2212}5`. Only before a number (or a currency sign and a digit: `-$20` adds `{U+2060}`), at the start or after whitespace, `(`, `[` or an opening quote. `COVID-19` and `a-5` are untouched.                   |
| `placeEmdash`                  | `a -- b`       | `a{U+00A0}{U+2014} b`. Also a spaced `-` between a word and a word, number or currency sign, and a line-start `-` (so a plain-text bullet becomes a dash). Left alone: `5 - 3`, `use --force`, `-->`. `en`, `ru`. |
| `placeNumericRange`            | `10-20`        | `10{U+2060}{U+2013}{U+2060}20`. A tight hyphen between two numbers. `en`, `ru`.                                                                                                                                   |
| `placeMathematicalSymbols`     | `\pm`          | `{U+00B1}`. Also `\infty`, `\times`, `\leq`/`\geq` (slanted U+2A7D/U+2A7E), `\degree` and more.                                                                                                                   |
| `placeGreekSymbols`            | `\alpha`       | `{U+03B1}`. LaTeX names, case-sensitive (`\Delta` is not `\delta`).                                                                                                                                               |
| `placeTypographyOrnamentation` | `\dinkus`      | `{U+2217}{U+2060}{U+2217}{U+2060}{U+2217}`. Also `\S`, `\P`, `\dag`, `\copyright`, `\trademark`.                                                                                                                  |
| `placeEmoticons`               | `\shrug`       | The emoticon, joined with `{U+2060}` so it never breaks. Also `\crying`, `\happy` and more.                                                                                                                       |
| `placeCurrencySymbols`         | `\euro`        | `{U+20AC}`. Also `\pounds`, `\yen`, `\ruble`, `\tenge`. Typed signs and codes (`$100`, `USD 100`) are left as written.                                                                                            |
| `placeNbsp`                    | `it is a test` | `it is a{U+00A0}test`. Binds the space after a short word, and after a spaced `&`. `en`, `ru`.                                                                                                                    |
| `placeHyphen`                  | `e-mail`       | `e-{U+2060}mail`. A tight hyphen between Latin or Cyrillic words, the shorter at most 3 letters. Unspaced runs that look like identifiers are left alone.                                                         |
| `placeTemperatureSign`         | `100oC`        | `100{U+00B0}C`. Also `oF`. The unit must touch the number.                                                                                                                                                        |
| `placeMultiplicationSign`      | `3 x 4`        | `3{U+202F}{U+00D7}{U+202F}4`. `x`, `X` or `{U+00D7}` between two numbers. `1920x1080` gives `1920{U+00D7}1080`; `0x10` is declined.                                                                               |
| `formatInitials`               | `J. Smith`     | `J.{U+00A0}Smith`. Chained initials use `{U+202F}` (`J. K. Smith`). Not handled: `Mr. Smith`.                                                                                                                     |
| `placeTypographicQuotes`       | `"hello"`      | `{U+2018}hello{U+2019}` in `en`. Nesting alternates by depth. Apostrophes: `it's`, `dogs'`, `'90s`, `'em`. Measurements (`5'10"`), unpaired quotes and a `'` opening before a number (`'1984'`) are left.         |
| `placeArrows`                  | `item -> next` | `item {U+2192} next`. Also `<-`, `<->`. Declined: `->>`, `-->`, and `<-` tight before a number.                                                                                                                   |
| `placeShapes`                  | `\square`      | `{U+25A1}`. A `black` prefix gives the filled shape (`\blacksquare`). Also circles, triangles, stars, suits.                                                                                                      |

Whitespace rules (`placeNumberNbspWord`, `placeNbsp`, `formatInitials`, the dashes) convert only a single regular space. Newlines, repeated spaces and tabs are left as written, and no rule inserts whitespace.

Shortcodes are a backslash plus ASCII letters, case-sensitive, each gated by its own rule. Unknown names stay as written, a name directly followed by `{` (`\sqrt{2}`) is left as a LaTeX command, and `(c)`, `(tm)` are not converted. The full tables are in `src/core.js`; the sets may change.

## Per-element overrides

Any rule can be switched per element with a kebab-case `data-*` attribute, on or inside an `.alaska` element. It applies to the element and its descendants:

```html
<div class="alaska" data-place-emdash="false">a - b stays as written</div>
```

Use the exact values `"true"` and `"false"`. Any other non-empty value turns the rule on, a bare attribute turns it off, and non-rule attributes are ignored.

## Math zones

Prose rules never guess algebra, so `3 - 4` and `3 + 4` are left as written. Mark a formula with `data-math="true"` on or inside an `.alaska` element (inherits; `data-math="false"` restores prose; an explicit `data-place-*` on the same element wins):

```html
<p class="alaska" data-math="true">x - 5</p> <!-- x {U+2212} 5 -->
```

A zone turns `placeArithmeticalSymbols` on and `placeEmdash`, `placeNumericRange`, `placeHyphen`, `placeNbsp` off. Operators change glyph only: the author's spaces stay, and unit glue stays on (`x = 3 m`). A unary minus may also precede a word or follow `= + * / < >` (`x=-y`). Words are operands (`Therefore - note` gets a minus). `\star` and `\diamond` give the operators U+22C6 and U+22C4 (`data-math="false"` restores the glyphs). In the core, pass `{ ...commonRules, ...mathRules }`.

## What Alaska does not do

- **Code and identifiers.** Alaska formats prose. Put code, paths and identifiers in `<code>` or `alaska-skip`. A backslash plus a shortcode name expands anywhere (`C:\pi` gives `C:{U+03C0}`), and `<-` is an arrow (`x <- 5`).
- **Tell a range from a number pair.** A tight number-hyphen-number is a range: `555-1234`, `2024-01` and `10-5` get an en dash. Chains (`2024-01-15`) and a number after a word (`x86-64`) are left alone.
- **Read meaning.** Initials, short words and quotes are matched by shape. `Plan B. Then` binds the `B.`, `Vitamin A and C` binds the letters, `'The dogs' owners left'` closes early, `'Twas` reads as an opener, `'round the world,'` as an elision, and `10 % y` reads `%` as a percent sign.
- **Format across inline boundaries.** Lookahead rules decide within one piece, so `1-2<b>-3</b>`, `my-site<b>.example.com</b>` and `5-<b>star</b>` can be missed or wrong.
- **Unify character references.** The CLI passes a reference through as a word (`Tom &amp; Jerry` is not bound, `-&gt;` is not an arrow); the browser reads decoded text and does bind and convert.
- **Support other languages.** See [Language](#language).
